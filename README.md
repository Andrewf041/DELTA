# I.V.I. - Jarvis Core v2.1

Интеллектуальная визуальная система (ассистент), оптимизированная под мобильные и десктопные браузеры.

## Особенности
- Динамический расчет высоты экрана (`visualViewport`) для корректной работы с виртуальными клавиатурами на смартфонах.
- Встроенная локальная база знаний, калькулятор и парсер Wikipedia.
- Синтез речи (Text-to-Speech) для озвучивания ответов.

## Запуск
Просто откройте файл `index.html` в любом современном браузере или запустите через GitHub Pages.
